Sprint 4 - Modelagem de Banco de Dados

Objetivo:

Implementar o modelo físico do banco de dados em PostgreSQL, aplicando conceitos de integridade, desempenho, transações e segurança.

Desenvolvimento:

Foram desenvolvidas tabelas com chaves e restrições, índices para otimização de consultas, transações com controle de alterações, análises utilizando `EXPLAIN ANALYZE` e controle de acesso com usuários, roles, `GRANT` e `REVOKE`.

Tecnologias:

PostgreSQL
SQL
Visual Studio Code
GitHub
